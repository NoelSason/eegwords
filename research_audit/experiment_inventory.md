# Experiment inventory

Two eras of work exist. **Only era B is used in the paper.**

- **Era A (legacy, Aug 31 – Sep 1 2026).** Original `~/Desktop/EEGWords` repo, since deleted. Code,
  raw results and checkpoints are gone. What survives: per-cell accuracies echoed into a Claude
  session transcript (`research_audit/legacy/aug31_grid_cells_from_transcript.csv`, extracted from
  the monitor lines). The raw session log is not kept in this repository.
  Not reproducible, and its "reproduction" did not use the paper's documented configuration
  (10 epochs, lr 1e-3 instead of 100 epochs, lr 5e-4; per-channel standardisation that upstream
  does not apply). Its label-order analysis used the 6,681 *presented* sentences, not the 6,243
  released trials. Listed for completeness; superseded by era B.
- **Era B (this repo, Sep 30 2026).** Rebuilt from public sources: OpenNeuro ds005170 and the
  upstream code at commit e051c5b. Everything below is regenerated by
  `scripts/reproduce_main_results.sh`.

Common to all era-B EEG experiments: subject sub-01 (= paper's S1), task `imagine` unless stated,
39 classes, 6,243 released trials (all mapped by `textmaps.json`), 122 EEG channels (upstream's
`[:122]`), no normalisation beyond V→µV (as upstream), model = upstream ChiscoNet
(EEGNet-style CNN + 1 transformer layer + mean pooling, `eegwords/model.py`), AdamW wd 0.01,
batch 16, linear warmup 10% then linear decay, evaluation every 100 optimiser steps. Metric =
top-1 accuracy. Device: Apple MPS (float32).

Checkpoint rules read from the **same** run:
`upstream_max` = max over evaluations of test accuracy (the published rule);
`val_selected` = test accuracy at the evaluation with the highest validation accuracy
(validation disjoint from test; for grouped splits, validation = whole held-out training runs);
`final` = last evaluation.
